How traversal works

The traversal engine visits each property and passes context to a callback.

Callback-driven traversal

import startFunc from "./src/v2/index.js";

const visitNode = (key, value, path) => {
    console.log({ key, value, path });
};

startFunc(data, visitNode);

The intended callback receives the property key, its value, and its path. As the engine finds nested objects or arrays, it continues traversing and reports their nodes too.

What must be traversed?

  • Objects containing objects.
  • Objects containing arrays.
  • Arrays of primitive values.
  • Arrays of objects.
  • Nested and mixed arrays and objects.
  • Empty objects and arrays.
