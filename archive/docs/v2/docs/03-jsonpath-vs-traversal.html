JSONPath vs traversal

They are related to JSON navigation, but they solve different problems.

HomeTraversalFolder generation

JSONPath selects nodes

JSONPath is a query language. It is useful when you want to find values matching a query, such as every endpoint whose method is GET, even when those endpoints appear at different depths.

Our traversal engine visits nodes

Our goal is to walk through the JSON tree and invoke our callback as each node is visited. It is not primarily a query language.

TaskApproach
Read a known propertyDirect JavaScript access

Remember: JSONPath finds matching nodes; traversal visits the tree and gives our code an opportunity to act on each node.
