Folder generation

A first consumer of the traversal engine: turn JSON keys into directories.

HomeTraversalRoadmap

The example

Given this JSON:

{
  "api": {
    "v1": {
      "clinics": {
        "all": "show"
      }
    }
  }
}

The desired folder tree is:

generated/
└── api/
    └── v1/
        └── clinics/
            └── all/

In this experiment, every key becomes a folder, including the final all key. The value "show" does not become a file.

Keep responsibilities separate

The traversal engine should only report nodes. A separate folder-builder callback uses the path information and Node.js filesystem functions to create directories.

await mkdir(targetFolder, { recursive: true });

Using a predictable output directory makes the result easy to inspect and safe to regenerate.
