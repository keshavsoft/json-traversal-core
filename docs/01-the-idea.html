JSON Traversal Core · Project story

The idea

A JSON document is already a tree. We want one reusable mechanism to visit that tree.

HomeTraversalJSONPath

JSON already describes a hierarchy

{
  "api": {
    "v1": {
      "clinics": {
        "all": "show"
      }
    }
  }
}

When we know the exact structure, direct access is simple:

const value = data.api.v1.clinics.all;

But sometimes we want to process the whole structure, not just one known property. We may want to inspect every key, validate every node, create a folder tree, or eventually generate API files.

The project goal

Build a generic traversal core that can visit the nodes and notify a supplied callback. The core should not know whether the callback logs information, creates folders, validates data, or performs another task.

One traversal engine. Many possible consumers.
