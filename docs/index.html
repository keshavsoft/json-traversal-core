Project story

What are we building?

JSON Traversal Core explores a reusable way to walk through a JSON structure. Instead of writing a different recursive loop for every task, we provide JSON once and supply a callback that decides what to do when each node is visited.

Core principle: the traversal engine walks the tree; the caller decides what action to perform.
